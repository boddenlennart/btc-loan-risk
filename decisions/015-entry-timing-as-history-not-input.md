# 015 · Entry timing: shown as history, not an input

Date: 2026-10-23 · Status: in force

## Decision
What BTC did in the 90 days before a loan starts matters (example: after a fall 59 of 100 liquidated, all start days 42). It will be shown as a small table in the history section for the visitor's own loan and explained on Insights. It is not an input or expert setting.

## Why
It is market state, not a loan term; as an input it would turn the headline into a timing signal (advice-like); the data holds few independent cycles; it does not fit existing loans.

## Alternatives considered
An expert "what if" setting (rejected by the owner).

## Consequences
The table's total must equal the history number above it and use the loan's currency.
