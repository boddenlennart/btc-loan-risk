# iPhone check, with and without VoiceOver (about 30 minutes)

On your own iPhone, in Safari, on the preview address (https://ux-redesign.bitcoinloancheck.pages.dev) after pushing. Tick each line; for anything that fails, take a screenshot (side button + volume up) and write one sentence.

## Without VoiceOver (15 min)

1. [ ] The page opens and the number appears within a few seconds. Note the seconds: ___
2. [ ] While it opens, nothing jumps (does the text you start reading move down?).
3. [ ] "Use your own terms": type an amount. The keyboard shows numbers. The page does not jump while you type.
4. [ ] Turn the phone sideways and back: nothing overlaps or is cut off.
5. [ ] The four tiles under the number: every word and number is complete (no "US$22,50 / 1", no cut-off word).
6. [ ] Tap "with the liquidation risk": it opens "What it costs" with the heading visible.
7. [ ] "Compare an offer": the page scrolls up to the table. Change offer B's rate: the table updates.
8. [ ] Open every folded section; charts are readable; touching a chart shows values.
9. [ ] "Share": the share sheet opens. Send the link to yourself, open it: the same terms appear.
10. [ ] Dark mode (Control Centre): all text readable, charts visible.
11. [ ] Text size: Settings → Display → Text Size to the largest. Reload: nothing cut off, no sideways scrolling.
12. [ ] German: switch the language; repeat 5 and 6.

## With VoiceOver (15 min)

Turn on: Settings → Accessibility → VoiceOver (or triple-click the side button if set up). Swipe right to move, double-tap to activate.

1. [ ] The page title and the main heading are read first.
2. [ ] The number is read as a sentence ("54 of 100 simulated futures end with this loan liquidated within 12 months"), not as single fragments.
3. [ ] The 100 dots are read once as a picture with a summary, not 100 times.
4. [ ] Each field is read with its label ("Loan amount, text field"), and "?" buttons say what they explain.
5. [ ] After changing a value, the new number is announced without moving to it.
6. [ ] "Compare an offer": VoiceOver lands on the comparison table and reads its title.
7. [ ] The comparison table: reading a cell says which offer and which row it belongs to.
8. [ ] The rotor (two-finger turn) → Headings: the sections can be jumped to by their headings.

Write down every place where you did not know where you were or what would happen next.
